# M1 — connecting the local workspace

Draft only. The repository remains private; no post is published automatically.

## Draft for X

tgdeck now has a local Telegram login flow: API setup, phone, code and two-step
verification. After login, choose a chat and open its first live text column.

API details and session files stay outside the repo. The demo still uses only
fictional content for progress clips.

Next: more columns and better controls.

## Validation

Synthetic tests cover auth states, retries, secret-free responses/logging,
private storage, endpoint protection, rate limits, message updates and the
native TDLib loader. Browser checks use a fake Telegram client. Real account
verification is left to the owner, with no screen captures or session fixtures.
